# 픽토그램 수업 연구실 — 교사용 로그인·수식 자료 수정본

학생 화면은 기존의 관찰·힌트·처음 식·검증·수정·성찰 활동을 유지합니다.
교사는 별도 로그인 화면에서 인증한 뒤, 학생과 같은 그림 20개의 148개 부분에 대한 모범식을 볼 수 있습니다.

**이 프로그램은 Node.js 웹앱입니다. Streamlit 앱이 아닙니다.**
수정된 파일을 제공하는 것이며, 기존 인터넷 사이트를 자동으로 교체하거나 배포한 것은 아닙니다.

## 1. 달라진 점

- `/teacher/login`: 교사 아이디와 비밀번호를 입력하는 별도 로그인 화면.
- `/teacher`: 서버에서 교사 세션을 확인한 뒤에만 여는 자료 화면.
- `/api/teacher/data`: 로그인하지 않으면 `401`을 반환하는 수식 데이터 API.
- 원은 원의 방정식, 원호는 범위 조건이 붙은 원의 방정식, 직선은 범위 제한 선분, 점은 좌표로 표시합니다.
- 그림의 부분 이름을 선택하면 그림과 해당 수식 카드가 함께 강조됩니다.
- 부분별 식 복사, 전체 식 복사, 수식 텍스트 파일 저장, 인쇄를 제공합니다.
- ‘학생 화면으로’를 누르면 먼저 교사 세션을 로그아웃합니다.
- 지정되지 않은 외부 서버 주소로 이동하던 기존 링크를 없앴습니다. 같은 서버에서 실행하면 자동으로 현재 서버의 로그인 화면을 엽니다.

모범식 제공 범위는 **현재 앱에 포함된 픽토그램 20개**입니다.
새로 올리는 임의의 사진을 자동으로 수식화하는 기능은 포함하지 않습니다.

## 2. 가장 간단한 인터넷 배포: 학생·교사를 같은 Node 서버에서 실행

### GitHub에 수정본 올리기

1. 압축을 풀고 `pictogram-main` 폴더를 엽니다.
2. 그 안의 **파일과 하위 폴더를 모두** 앱 저장소에 반영합니다. `index.html`만 교체해서는 교사 로그인이 작동하지 않습니다.
3. 저장소 맨 위에서 `package.json`, `package-lock.json`, `server.js`, `index.html`, `render.yaml`이 보이게 합니다.
4. 실제 `.env` 파일과 교사 비밀번호는 절대로 GitHub에 올리지 마세요. `.env.example`은 빈 설정 예시이므로 포함해도 됩니다.
5. 교사용 소스와 테스트의 모범식이 학생에게 노출되지 않도록 서버용 저장소는 비공개로 관리하세요.

### Render에서 실행

Render에서 **New → Web Service**를 선택하고 저장소를 연결합니다.
이미 이 앱의 Node Web Service가 있다면 새 서비스를 만드는 대신 그 서비스에서 수정본을 다시 배포할 수 있습니다.

| 설정 | 입력값 |
|---|---|
| Language / Runtime | Node |
| Root Directory | 저장소 맨 위에 파일을 올렸으면 비워 둠 |
| Build Command | `npm ci` |
| Start Command | `npm start` |
| Health Check Path | `/healthz` |

`pictogram-main` 폴더째 저장소에 올려 파일이 한 단계 안쪽에 있다면,
**Root Directory를 `pictogram-main`으로 설정**해야 합니다.

서비스의 **Environment → Add Environment Variable**에서 다음을 설정합니다.

| Key | Value |
|---|---|
| `NODE_VERSION` | `22` |
| `HOST` | `0.0.0.0` |
| `NODE_ENV` | `production` |
| `TEACHER_USERNAME` | `teacher` 또는 선생님이 정한 아이디 |
| `TEACHER_PASSWORD` | 선생님만 아는 고유한 비밀번호, 14~512자 |

비밀번호는 `render.yaml`, `index.html`, `config.js`에 쓰지 않습니다.
`TEACHER_PASSWORD`를 비워 두거나 14자 미만으로 설정하면 학생 화면은 열리지만 교사 로그인은 잠긴 상태로 유지됩니다.
기본 비밀번호는 없습니다.

설정을 저장할 때 **Save, rebuild, and deploy** 또는 **Save and deploy**를 선택해 반영합니다.
처음 서비스 생성 중이면 환경 변수를 입력한 뒤 배포를 완료합니다.

다른 방법으로는 저장소의 `render.yaml`을 **New → Blueprint**에서 사용할 수 있습니다.
이 경우에도 `TEACHER_PASSWORD` 비밀 값을 직접 입력해야 합니다.

### 접속 주소

실제 배포가 끝나면 Render가 부여한 서비스 주소를 사용하세요.
이 안내서는 존재하지 않는 서비스 주소를 미리 지정하지 않습니다.

```text
학생 화면:    https://실제-서비스-주소/
교사 로그인:  https://실제-서비스-주소/teacher/login
교사 자료:    https://실제-서비스-주소/teacher
```

학생 화면의 **교사용 로그인** 버튼으로도 이동할 수 있습니다.
학생 화면에서 선택한 그림이 있으면 로그인 후 그 그림의 수식이 열립니다.

사용자 지정 도메인을 연결했다면 `APP_ORIGIN`을 실제 접속 원점으로 지정하세요.
예: `https://math.example.org` (경로 없이 도메인까지만).
일반 Render 주소에서는 제공되는 `RENDER_EXTERNAL_URL`을 사용합니다.

## 3. 기존 GitHub Pages 학생용 주소를 유지할 때

GitHub Pages는 정적 호스팅이므로 이 앱의 Node 인증 서버를 실행하지 못합니다.
교사 로그인에는 별도의 Node Web Service가 필요합니다.
HTML 안에 비밀번호를 넣거나 브라우저에서만 역할을 바꾸는 방식으로 대신하지 마세요.

먼저 위 방법으로 Node 서버를 배포한 다음, 학생용 `config.js`만 아래처럼 설정합니다.

```javascript
window.PICTO_CONFIG = Object.freeze({
  serverMode: false,
  teacherBaseUrl: "https://실제로-배포된-서버-주소"
});
```

주소 끝에는 `/teacher`나 `/teacher/login`을 붙이지 말고 서버 주소만 입력합니다.
이 값은 비밀번호가 아니라 공개 로그인 페이지의 주소입니다.

그다음 아래 명령을 실행합니다.

```sh
npm run build:student
```

생성된 `dist/student` 폴더의 내용만 GitHub Pages에 게시하세요.
이 폴더에는 학생 화면과 로그인 서버 연결 안내에 필요한 정적 파일만 들어 있습니다.
교사 서버 소스, 교사용 실행 스크립트, 수식 API 데이터, 테스트는 포함되지 않습니다.

Node 서버에서 제공하는 `/config.js`는 서버가 자동으로 생성하므로,
Node 서버 안의 학생·교사 화면은 외부 주소 설정 없이 같은 서비스에서 연결됩니다.

다른 도메인으로 옮기면 기존 학생 기록이 자동 이동하지 않습니다.
학생은 기존 주소에서 **기록 파일 저장**을 한 다음 새 주소에서 기록 파일을 불러오세요.
서버 교체 자체는 학생의 브라우저 기록을 서버로 전송하지 않습니다.

## 4. 내 컴퓨터에서 먼저 확인하기

Node.js 22.x의 22.9.0 이상 버전을 준비하고, 압축을 푼 앱 폴더에서 실행합니다.

```sh
npm ci
npm run setup
npm start
```

`npm run setup`은 고유한 무작위 비밀번호를 만들고, 로컬 `.env`에 저장합니다.
터미널에 표시되는 아이디와 비밀번호를 개인적으로 보관하세요.
이 명령은 기존 `.env`를 덮어쓰지 않습니다.

```text
학생 화면:    http://localhost:3000/
교사 로그인:  http://localhost:3000/teacher/login
```

로컬 실행을 위해 만들어진 `.env`를 저장소나 학생 배포 파일에 넣지 마세요.
Render에서는 로컬 `.env`를 업로드하는 대신 Environment에 값을 직접 설정하면 됩니다.

## 5. 계정과 보안 동작

현재는 관리자가 지정하는 **단일 교사 계정** 방식입니다.
학생용 계정 생성이나 공개 회원가입 경로는 없습니다.
아이디는 `TEACHER_USERNAME`, 비밀번호는 `TEACHER_PASSWORD`로 바꾸고 서버를 다시 배포합니다.

인증은 Node 서버에서 처리합니다. 주소의 `role=teacher` 같은 값이나 브라우저의
`localStorage` 값을 교사 권한으로 사용하지 않습니다.

서버가 발급한 무작위 세션 쿠키를 사용하며, 쿠키에는 비밀번호나 수식을 넣지 않습니다.
쿠키는 `HttpOnly`, `SameSite=Strict`를 사용하고 운영 환경에서는 `Secure`도 사용합니다.
실제 운영은 HTTPS를 사용하세요.

로그인 세션은 8시간 후 만료됩니다. 서버 재시작·재배포 시에도 다시 로그인해야 합니다.
로그아웃하면 서버 세션을 삭제하므로 이전 쿠키를 재사용해도 자료를 받을 수 없습니다.
같은 브라우저의 다른 교사 탭에도 로그아웃을 알리고, 자료 화면은 다시 활성화될 때 인증 상태를 확인합니다.

동일 아이디의 로그인 실패 5회 이후에는 최대 15분간 재시도를 제한합니다.
IP별 보조 제한도 있습니다. 출처가 다른 로그인 요청과 잘못된 로그아웃 토큰을 거부합니다.

### 중요한 운영 한계

교사 비밀번호를 아는 학생이나 **이미 로그인한 교사의 기기**를 사용하는 학생을
시스템이 실제 교사와 구분할 수는 없습니다.
공용 기기에서는 비밀번호 저장을 피하고 수업 후 반드시 로그아웃하세요.

이미 다운로드하거나 인쇄·캡처한 자료까지 회수할 수는 없습니다.
학생에게 보여 주는 그림·좌표·학습 힌트로 수식을 스스로 유도하는 것은 학습 활동이며 차단 대상이 아닙니다.
이 수정의 목적은 **교사용 완성 수식 자료에 대한 무인증 접근을 막는 것**입니다.

세션과 로그인 실패 횟수는 서버 메모리에 보관합니다.
이 구성은 단일 Node 인스턴스를 기준으로 합니다. 서버를 여러 대로 확장하려면
공유 세션 저장소와 공유 요청 제한 저장소를 추가해야 합니다.
학교 계정 연동이나 교사별 독립 계정이 필요한 경우에는 별도 계정 관리 설계가 필요합니다.

## 6. 수식의 의미와 정확도

전체 148개 부분은 원 13개, 원호 12개, 선분 118개, 점 5개로 구성됩니다.
각 부분은 하나의 모범식으로 정리됩니다. 다른 수학적으로 동치인 식도 가능합니다.

원호는 원의 방정식에 범위를 제한합니다.
기존 그림의 SVG는 원호를 작은 선분들로 그리므로, 수업용 원호 모델과
화면 윤곽선 사이에는 미세한 차이가 있습니다.
서버는 경로의 좌표가 원 위에 놓이는지 확인하고, 지원하지 않는 새 도형은
틀린 식을 조용히 만드는 대신 오류로 거부합니다.

점 부분의 `r=0.13`은 화면에서 점을 보이게 하는 표식 크기이므로,
교사 수식은 그 작은 원의 방정식이 아니라 `(x좌표,y좌표)`를 제공합니다.

중괄호 `{ }` 안의 범위 조건까지 함께 입력하세요.
전체 식 복사는 한 줄당 하나의 식만 내보내며, 부분 이름을 식 앞에 붙이지 않습니다.
브라우저에서 자동 복사가 차단되면 직접 선택할 수 있는 복사 창이 열립니다.
실제 Desmos 사이트에 식을 자동 제출하거나 그래프를 자동 저장하지는 않습니다.

## 7. 검사

```sh
npm test
```

Node 자동 검사 24개를 포함했습니다.
수식은 원본 좌표 및 샘플 점 2,455개와 비교했습니다.
자세한 검사 범위와 실행 환경의 한계는 `TEST_REPORT.md`에 기록했습니다.

배포 후에는 반드시 아래 순서로 확인하세요.

1. 새 시크릿 창에서 학생 화면과 교사 로그인 화면이 열리는지 확인합니다.
2. 로그인하지 않은 상태로 `/teacher`에 접속했을 때 로그인 화면으로 이동하는지 확인합니다.
3. 설정한 교사 계정으로 로그인하여 그림과 수식이 보이는지 확인합니다.
4. 로그아웃한 뒤 `/api/teacher/data`를 열었을 때 `교사 로그인이 필요합니다`라는 응답이 나오는지 확인합니다.
5. 학생에게는 학생용 주소만 안내하고, 비밀번호·수식 내보내기 파일은 공유하지 않습니다.

## 8. 주요 파일

```text
index.html              기존 학생 화면과 학습 데이터
config.js               정적 학생 화면의 교사 서버 주소 설정
teacher-login.html      별도 교사 로그인 화면
login.js                로그인 요청 및 서버 미설정 안내
teacher.html            인증 후 제공하는 교사 자료 화면
teacher.js              그림 강조·수식 표시·복사·저장·로그아웃
teacher.css             교사 화면의 데스크톱·모바일 디자인
server.js               서버 인증·세션·접근 제어
geometry.js             서버에서 SVG를 수업용 모범식으로 변환
scripts/setup.js        로컬 무작위 비밀번호 생성
scripts/export-student.js  학생용 정적 배포 파일 내보내기
test/server.test.js     자동 검사
render.yaml             Render 배포 설정
.env.example            비밀 값이 없는 설정 예시
```
